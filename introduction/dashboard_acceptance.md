# 本地 HTML 观测台验收

界面使用 HTML/CSS/原生 JavaScript 和 SVG，不需要 Node.js、npm、前端框架或在线资源。HTTP 服务使用 Python 标准库，仅提供静态文件和只读 `GET /api/state`，没有修改节点或链状态的接口。

## 启动

在两个终端分别从仓库根目录执行：

```bash
conda activate blocknode
cd codes
```

终端 A：计算五个区块并提供观测页面。

```bash
python -m blocknode --config config/genesis.json --data-dir data/ui-a --listen 127.0.0.1:9201 --dashboard 127.0.0.1:8080 --blocks 5
```

浏览器打开 `http://127.0.0.1:8080`。本地包是可编辑安装，当前 MacBook 无需重新安装，也不用安装新的依赖。

终端 B：连接 A，作为验证同步节点。

```bash
python -m blocknode --config config/genesis.json --data-dir data/ui-b --listen 127.0.0.1:9202 --peer 127.0.0.1:9201 --blocks 0
```

首次使用上述目录时，A 和 B 同步到高度五。已有目录则继续原有链。HTTP 端口与节点 TCP 端口必须不同；示例全部绑定本机回环地址，不向其他机器开放。

## 检查界面

1. **累计量**：当前链累计量为五，创世块不计入；标题处显示真实节点 ID 和 TCP 监听地址。
2. **区块图**：青色为当前链，若有经过验证的旁支则以琥珀色显示。图可横向滚动，最近二十个高度范围内的区块可见。点击区块或用键盘 Enter/空格选择，右侧显示完整哈希、父哈希、生成节点、Nonce 和累计工作量。刷新不会清除手动选择。
3. **连接视图**：B 完成握手后，A 显示一个直接连接；节点名称为真实 ID 的短形式。地址是实际 TCP 连接端点，入站连接的源端口不一定等于对端的监听端口。
4. **计算曲线**：A 显示本次运行中每次完成 PoW 搜索的平均速率；B 不主动计算，因此没有本地速率样本。曲线按搜索完成的先后顺序排列，最多保存 120 次样本，不填充虚构值。
5. **断线更新**：在 B 按 Ctrl+C，A 的连接数在下一轮更新后变为零，事件列表出现 `DISCONNECTED`，累计量不改变。出块、接收、同步完成和重组记录可展开查看关联的完整区块哈希。重新启动 B 后可再次看到连接与同步事件。
6. **只读与断开**：页面没有转账、奖励、修改难度或远程出块按钮。A 停止后页面标注数据连接中断，不把最后一份快照当成仍在实时更新。

节点每半秒生成不可变 JSON 快照，页面每秒轮询一次。HTTP 线程只读取快照，不跨线程共用 SQLite 连接。界面更新存在这个轮询延迟。

直接连接图仅表示本节点当前会话；对端高度和链头属于最近通告，不是完整全网实时拓扑或独立远程遥测。没有采集的 CPU 温度、内存和对端算力不显示为伪造数字。

搜索速率为 `attempts / 搜索耗时`，网络模式耗时包含事件循环让出期间的墙钟时间。它不是固定工作量基准、专用 SHA 内核吞吐或性能优化结论；完成计算后展示的是最近一次结果。

## 视觉与交互验证记录

本机已通过 31 项自动测试，包含 HTTP 静态资源与 API、只读限制、旁支和累计量区分，以及原有 TCP 与持久化测试。

浏览器验收使用本机已有 Chrome 的独立无界面会话，检查了桌面 1512px 和窄屏 390px：无页面横向溢出、无 JavaScript 异常、无外部资源请求，旁支选择和刷新后保留详情通过。内置浏览器连接工具超时，因此未据此声称其预览通过。

截图保存在 `figures/dashboard-preview.png` 和 `figures/dashboard-mobile-preview.png`。其中高度 17、三个旁支块、五次计算样本及一个 peer 都来自实际计算、验证和连接过的本机节点，不是页面填充数据。新建的直线链不会自动出现这些测试分支。

截图样本和事件只保留在对应运行进程内；重启后不伪造或重建历史速率曲线。链与旁支仍保存在 SQLite。

## 测试和停止

从 `codes/` 执行：

```bash
python -m unittest discover -s tests -v -b
```

预期 31 项通过。网络测试需要本机回环 TCP/HTTP 权限。验收完在两个终端分别按 Ctrl+C，结束节点与 HTTP 服务，数据库继续保留。

该界面仍仅是本节点只读观测台；没有实现网页操作、全网遥测聚合、原生计算优化或 Pi/PC 实机验证。
